## Project Overview
This is a personal portfolio website built from scratch using HTML and CSS. The website follows best practices in web development, including accessibility, semantic HTML, and responsive design.

## Features
- **Grid Layout & Flexbox**: Utilized to structure the content efficiently.
- **Responsive Design**: Optimized for both desktop and mobile screens.
- **Accessibility & Best Practices**: Ensured proper semantic HTML, metadata, and A11y standards.
- **No CSS Frameworks**: Styled entirely with custom CSS.
- **Five Pages**: The website consists of Home, About, Portfolio, Blog, and Contact pages.

## How to Run the Project
1. Clone the repository:
   ```sh
   git clone <https://github.com/dobleh16/portfolio-css.git>
   ```
2. Open `index.html` in a browser.

## Git Workflow
Each team member works on their own branch and merges updates into a shared branch. Follow these steps to contribute:
1. Create a new branch:
   ```sh
   git checkout -b feature-branch
   ```
2. Make changes and commit:
   ```sh
   git add .
   git commit -m "Description of changes"
   ```
3. Push the branch:
   ```sh
   git push origin feature-branch
   ```
4. Create a pull request and merge after review.
